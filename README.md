## Instalação

> OBS: E NECESSARIO CONFIGURAR O ARQUIVO .ENV

1. Clonar o repositório:

    ```bash
    git clone https://github.com/7feeh7/template-api-fastify.git
    ```

2. Instalando as dependências:

    ```bash
    yarn install
    ```

3. Inicie o servidor local:

    ```bash
    yarn run start:dev
    ```
